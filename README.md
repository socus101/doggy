# Doggy — เวอร์ชัน 3.6

## มีอะไรใหม่ใน v3.6

### 💰 หลักการคิดเงินแบบใหม่
| ตัวเลข | คิดอย่างไร |
|---|---|
| **กำไรจากการขาย** | ยอดขาย − ต้นทุนของชิ้นที่ขายไป · **ซื้อของเข้ามาเติมไม่ทำให้กำไรลด** |
| **เงินทุนหมุนเวียน** | ยอดขาย − ซื้อของด้วยเงินยอดขาย − ตัดกำไรเข้ากระปุก + ย้ายเงินกระปุกกลับมา · ถ้าติดลบ = "ค้างหัก" จะหักจากยอดขายถัดไปเอง |
| **ทุนที่ควักเพิ่ม** | ซื้อของที่เลือก "ควักทุนเพิ่ม" · ไม่หักจากเงินที่ขายได้ |

- ทุกครั้งที่ซื้อของ (เพิ่มสินค้าใหม่, เพิ่มวัตถุดิบ, เติมของ) มีตัวเลือก 💵 **ใช้เงินจากยอดขาย** (ค่าเริ่มต้น) หรือ 💼 **ควักทุนเพิ่ม** · ถ้าเงินไม่พอจะบอกว่าขาดเท่าไรและจะหักจากยอดขายถัดไป
- **รายการซื้อเข้าเก่าทั้งหมด (ก่อน v3.6) นับเป็น "ใช้เงินจากยอดขาย" อัตโนมัติ** · เปลี่ยนทีละรายการได้โดยแตะป้าย 💵/💼 ในตาราง "ประวัติซื้อเข้า"
- หน้าสรุปยอด: การ์ดเปลี่ยนเป็น ยอดขาย / ต้นทุนของที่ขายไป / กำไรจากการขาย + แผง **กระเป๋าเงินร้าน**
- 📒 **ที่มาที่ไปของเงิน**: ทุกรายการเงินเข้า-ออก พร้อมยอดคงเหลือ และอธิบายยอดค้างหัก

### 🐷 กระปุกออมสิน (เมนูใหม่)
- ตัดกำไรเข้ากระปุก ระบุจำนวนเองได้ · เลือกตัดของเดือนไหน หรือรวมทุกเดือน
- ตารางกำไรแยกรายเดือน (กำไร / ตัดแล้ว / ยังไม่ตัด / ออกจากกระปุก)
- 🔁 ย้ายเงินกระปุกกลับไปเป็นทุนซื้อของ · 💸 นำออกไปใช้ภายนอก · ประวัติทุกรายการ

### 🍹 สินค้าผลิตเอง + สูตรวัตถุดิบแฝง
- ตอนเพิ่มสินค้าเลือกได้ 🛍️ ซื้อมาขาย หรือ 🍹 ผลิตเอง → ตั้งสูตรว่าใช้วัตถุดิบอะไรเท่าไรต่อแก้ว (หรือ "1 ถุงทำได้กี่แก้ว")
- ระบบคิด **ต้นทุนจริงต่อแก้ว** และ "ทำได้อีกกี่แก้ว" จากวัตถุดิบที่มี · ขายแล้วตัดวัตถุดิบให้อัตโนมัติ · ยกเลิกบิลคืนวัตถุดิบ
- วัตถุดิบมีหน่วยนับ, ปุ่ม ⛔ หมด, ➕ เติมของ (ต้นทุนรอบใหม่เท่าเดิม/มากกว่า/น้อยกว่าก็ได้ ระบบเฉลี่ยทุนให้ และสูตรคิดต้นทุนใหม่เอง)
- หน้าขาย: แยกประเภท 🛍️ ซื้อมาขาย / 🍹 ผลิตเอง · หน้าคลังแยกหัวข้อตามประเภท

> ⚠️ อัปโหลดทั้ง `doggy_webapp.html` และ `sw.js` (CACHE_VERSION เป็น `doggy-v10` แล้ว) · แนะนำ **ดาวน์โหลดไฟล์สำรองก่อนอัปเดต**

# ประวัติ: เวอร์ชัน 2

## มีอะไรใหม่ใน v2

| เรื่อง | รายละเอียด |
|---|---|
| 🐞 **แก้ยอดขายหายหลังเครื่องดับ** | สาเหตุ: ทุกบิลเก็บ "รูปสินค้า" ซ้ำลงไป ทำให้พื้นที่ localStorage (~5MB) เต็ม พอเต็ม ระบบบันทึกสินค้าได้แต่บันทึกยอดขายไม่ลง (แบบเงียบ ๆ) ยอดเลยหายตอนเปิดเครื่องใหม่ — ตอนนี้ย้ายไปเก็บใน **IndexedDB** (จุได้หลายร้อย MB), บิลไม่เก็บรูปซ้ำแล้ว, บันทึกแบบเขียนลงดิสก์จริงทันที และถ้าบันทึกพลาดจะมี **แถบแดงเตือน** |

| 🧾 หน้าขายแบบ POS | ค้นหา/ยิงบาร์โค้ด, หมวดหมู่, แตะสินค้าใส่ตะกร้า, ส่วนลดทั้งบิล (บาท/%), ชำระเงินสดพร้อมคำนวณเงินทอน หรือโอน/QR, ใบเสร็จพิมพ์ได้/บันทึกเป็นรูป |
| 🛠️ เครื่องมือ | ตั้งค่าภาษี (เปิด/ปิด, กี่ %, บวกเพิ่ม หรือ รวมในราคาแล้ว), ชื่อร้าน/ข้อความท้ายใบเสร็จ, อัปโหลดรูป QR Code และเปิด/ปิดการแสดงบนใบเสร็จ |
| 📱 แท็บเล็ต | จัดหน้าใหม่ให้พอดีทั้งแนวนอน/แนวตั้ง ปุ่มใหญ่กดง่าย มือถือมีแถบตะกร้าด้านล่าง |
| ⏰ เตือนเวลาเครื่องผิด | ถ้านาฬิกาแท็บเล็ตย้อนเวลา (เช่น แบตหมดแล้วเวลารีเซ็ต) จะขึ้นแถบเหลืองเตือน เพราะยอด "วันนี้" จะดูเหมือนหาย |

> 📅 หน้าสรุปยอดเริ่มที่ "วันนี้" ถ้าช่วงที่เลือกไม่มีรายการ จะมีแถบเหลืองบอกวันที่ของข้อมูลล่าสุด พร้อมปุ่ม "ดูยอดทั้งหมด" และหลังกู้คืนไฟล์สำรอง ระบบจะตั้งเป็น "ทั้งหมด" ให้อัตโนมัติ พร้อมบอกว่าในไฟล์มีกี่บิล
>
> หมายเหตุ: ยอดขายในหน้าสรุปยอด **ไม่รวมภาษี** (ภาษีเป็นเงินที่เก็บแทนรัฐ) ยอดภาษีที่เก็บได้จะแสดงแยกไว้ใต้กล่องสรุป
> การลบประวัติการขาย ตอนนี้จะ "ยกเลิกทั้งบิล" และคืนของทุกชิ้นในบิลเข้าสต็อก

# วิธีติดตั้ง (PWA ใช้งานออฟไลน์ได้)

## ไฟล์ทั้งหมดที่ต้องอัปโหลด

อัปโหลดเข้า repo `doggy` **ให้ครบทุกไฟล์ และรักษาโครงสร้างโฟลเดอร์ตามนี้**
(ถ้าขาด `sw.js` หรือโฟลเดอร์ `vendor/` แอปจะใช้ออฟไลน์ไม่ได้)

```
doggy/
├── doggy_webapp.html          ← ตัวแอป (แก้แล้ว)
├── index.html                 ← หน้า redirect เข้าแอป
├── manifest.json              ← ข้อมูลแอปสำหรับติดตั้งลงหน้าจอ
├── sw.js                      ← Service Worker (หัวใจของการใช้ออฟไลน์)
├── vendor/
│   ├── chart.umd.min.js       ← Chart.js (เดิมโหลดจาก CDN)
│   └── html2canvas.min.js     ← html2canvas (เดิมโหลดจาก CDN)
└── icons/
    ├── icon-192.png
    ├── icon-512.png
    └── icon-512-maskable.png
```

---

## วิธีติดตั้งบนแท็บเล็ต Android

1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub แล้วรอ 1-2 นาทีให้ GitHub Pages อัปเดต
2. บนแท็บเล็ต **ลบไอคอน Doggy เดิมออกจากหน้าจอก่อน** (สำคัญ ไม่งั้นจะยังใช้ของเก่า)
3. **เปิด Chrome ตอนที่มีเน็ต** ไปที่ https://socus101.github.io/doggy/
4. **รอประมาณ 5-10 วินาที** ให้ Service Worker โหลดไฟล์ลงเครื่องจนครบ
5. กดเมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
6. ปิด Wi-Fi และเน็ตมือถือ แล้วเปิดจากไอคอน → ต้องใช้งานได้ครบทุกปุ่ม

### วิธีเช็คว่าติดตั้งสำเร็จจริง
เปิดแอปตอนออฟไลน์ ถ้าเห็นป้ายข้าง ๆ ชื่อ 🛒 Doggy ขึ้นว่า **🔌 ออฟไลน์** แสดงว่าแอปทำงานจากไฟล์ในเครื่องแล้ว

## ⚠️ สิ่งสำคัญที่ต้องจำ

### 1. แก้ไฟล์ทีไร ต้องเปลี่ยนเลขเวอร์ชันทุกครั้ง
ทุกครั้งที่แก้ `doggy_webapp.html` ให้เปิด `sw.js` แล้วแก้บรรทัดนี้:

```js
const CACHE_VERSION = 'doggy-v4';   // → ครั้งหน้าเปลี่ยนเป็น 'doggy-v5', 'doggy-v6' ...
```

**ถ้าไม่เปลี่ยน แท็บเล็ตจะยังใช้ไฟล์เก่าที่แคชไว้** และจะงงว่าทำไมแก้แล้วไม่เปลี่ยน

### 2. สำรองข้อมูลสม่ำเสมอ
ข้อมูลร้านทั้งหมด (สินค้า ยอดขาย สต็อก คู่ค้า การตั้งค่า) เก็บอยู่ใน IndexedDB ของเบราว์เซอร์เครื่องเดียว
ถ้าล้างข้อมูลเบราว์เซอร์ / ถอนการติดตั้งแอป **ข้อมูลจะหายทั้งหมด**

→ กด **💾 สำรองข้อมูล → ⬇️ ดาวน์โหลดไฟล์สำรอง (.json)** อย่างน้อยเดือนละครั้ง
→ เครื่องใหม่หรือข้อมูลหาย ใช้ **⬆️ กู้คืนจากไฟล์สำรอง** ได้เลย

### 3. ฟอนต์
ตอนออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน Noto Sans Thai หน้าตาจะต่างเล็กน้อย แต่ใช้งานได้ปกติทุกอย่าง

## สรุปสิ่งที่แก้จากไฟล์เดิม

| ปัญหาเดิม | แก้เป็น |
|---|---|
| ไม่มี Service Worker → ออฟไลน์เปิดไม่ได้ | เพิ่ม `sw.js` แคชทุกไฟล์ลงเครื่อง |
| Chart.js / html2canvas โหลดจาก CDN → ออฟไลน์แล้วปุ่มวิเคราะห์พัง | ย้ายมาไว้ในโฟลเดอร์ `vendor/` |
| ส่งข้อมูลขึ้นชีตแบบยิงทิ้ง → ออฟไลน์แล้วข้อมูลหายจากชีตถาวร | ทำคิวเก็บใน localStorage ส่งตอนเน็ตกลับ |
| ไม่รู้ว่าตอนนี้ซิงก์แล้วหรือยัง | เพิ่มป้ายสถานะบนหัวเว็บ |
| ข้อมูลอยู่ในเครื่องอย่างเดียว ไม่มีทางสำรอง | เพิ่มปุ่ม export / import ไฟล์ .json |
| ไลบรารีโหลดไม่ครบ = แอปค้างทั้งหน้า | ใส่การ์ดกัน ทำงานต่อได้ |
| Add to home screen ได้แค่ bookmark | เพิ่ม `manifest.json` + ไอคอน เป็นแอปเต็มจอ |
